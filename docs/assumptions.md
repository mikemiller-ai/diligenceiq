## C. Query interpretation

| # | Assumption | Handling |
|---|---|---|
| C1 | "Last N years" is ambiguous relative to today (2026-10) versus the corpus. | **Rule:** resolved per company and corpus-relative: the N most recent **complete fiscal years** (by 10-K) for that company, plus any later quarters shown separately as "FY<next> YTD". Always displayed in the Interpretation panel and locked by a unit test. **Example (verified):** NVDA's latest 10-K covers FY2025 (period ended 2025-01-26), and its 10-Qs run through the quarter ended 2025-10-26. "Last two years" therefore resolves to FY2024 + FY2025 (complete), plus FY2026 YTD (Q1–Q3, through 2025-10-26) labeled separately. **Phase 3 query fix:** "last few years", "several years" and a plural with no count ("recent years") are read as 3, and "last couple of years" as 2, each flagged in the notes. "Year over year" or "compared with the prior year", with no year named, is read as the last 2 fiscal years and flagged. Two-digit years count only with the FY prefix ("FY23", "FY'23" → FY2023). |
| C2 | "Major pharmaceutical companies" maps to a curated sector list from the corpus (e.g. JNJ, PFE, MRK, LLY, ABBV). TMO and UNH count as healthcare but not pharma. | A static GICS-style map lives in `packages/corpus`. It is deterministic, documented, and shown in the Interpretation panel. |
| C3 | Company names and tickers collide with ordinary English. | **Names** that are common words (Target, Visa, Oracle, Meta, Apple, Caterpillar…) match only as case-sensitive capitalized words. **Tickers** that are short or English words (V, T, MA, GE, BA, TGT, MS, DE, HD, PG, CAT, KO…) match only as uppercase standalone tokens (not adjacent to a letter, digit, `-`, `&`, `.`, or apostrophe). Unit tests: "the target market" → no TGT; "Target's margins" → TGT; "a T-shaped team" → no T; "AT&T and T-Mobile" → AT&T only via its name; "visa requirements" → no V; "Visa and MA" → V + MA; "meta-analysis" → no META; "apple supply" → no AAPL; "MS and GS" → MS + GS; "ms. smith" → no MS. **Phase 3 query fix:** the common-word list is trimmed to genuine English words and given names (Apple, Target, Visa, Oracle, Meta, Caterpillar, Amazon, Chase, Intel, Chevron, Coke, Lilly, Alphabet). Brand-only names (Tesla, Google, Boeing, Nike, …) match case-insensitively. A lowercase common-word name next to other named companies gets a note that it was read as a word. A likely company that is not in the corpus (a curated list such as Ford, or a capitalized name before Inc/Corp/Ltd) gets a stated gap, "Ford is not in the corpus (54 companies)". |
| C4 | Topic keywords should help retrieval, never restrict it. | Topics apply soft section boosts only, never filters. |
| C5 | A question that names no period should not silently mix years. | **Default "current view":** per company, the latest 10-K plus any subsequent 10-Qs. Shown in the Interpretation panel; user filters override it. **Phase 3 query fix:**<br>• **Time-phrase rule:** a bare year counts as a period only after a temporal preposition ("in 2024", "as of 2024", "ended 2024"), before a filing word ("the 2024 10-K", "2024 results"), or in a list joined to a counted year. A year after an event verb ("enacted in 2022", "launched in 2020") never counts. Uncounted years get the note "Not read as a period (no time phrase…)".<br>• **Fallback:** a named period with no filing for any company in scope falls back to the current view. The analysis keeps it as `requestedPeriod` and states a gap per named company, "AAPL: no FY2015 filing in the corpus; showing the current view instead", plus a note. A user's fiscal-year filter never falls back. When only some named companies lack it ("Compare Apple and Merck in 2022"), each of those keeps a lane in its current view, with the gap "MRK: no FY2022 filing in the corpus; showing its current view (FY2024) instead." and a note, so a comparison never silently loses a company. A dash-only range ("2025-2030") follows the time-phrase rule like a bare year; "from…", "between…" and "to/through/until" ranges always count.<br>• **Review window:** a company whose every filing ends more than 3 years before the corpus's newest period end (GE, FY2014 only) is left out of questions that name no company, with a note. It is still searched when named.<br>• **One period in scope:** a change question in which a named company has only one period in scope gets a note on how to name years to compare. |
